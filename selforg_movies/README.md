# 自己組織化モデルの動画

NEURONS ボードゲームのピースと配線規則から作った興奮性媒質。ニューロン = カード中心の丸(白 = 興奮性 / 黒 = 抑制性)、
配線 = カードの線。すべて**ノイズゼロの決定論的**進化で、`neurons_selforg.html` と同じエンジン・同じ配色です。

`paper/` と `glow/` に同じ内容が2つの配色で入っています。同一のシミュレーションから書き出しているので、
両者はフレーム単位で同一です。`paper` はアプリの既定(クリーム地に朱と青のインク)、`glow` は暗背景の発光表示で、
プロジェクタ投影ではこちらの方がコントラストが出ます。

**色の読み方** — 暖色(朱/黄)= 白ニューロンの発火、寒色(青)= 黒ニューロンの発火、
褪せた色 = 不応期の残光、**マゼンタ = 双子宇宙との差分**。

## 主なもの

| ファイル | 相 | 設定 |
|---|---|---|
| `spiral` | **秩序** — 自励回転するスパイラル波 | cross=0.7, q=1.0, R=14, 破断波から起動 |
| `ordered` | **秩序** — 回路フィードバック OFF | 下の `chaos` と**配線パラメータが完全に同一**で faceA だけが 0 |
| `chaos` | **カオス** — 沸騰する乱流 | 同上 + faceA=2 |
| `damage` | **ダメージ伝染** — 1ノード反転が盤の 69% に広がる | `chaos` と同設定、seed 303 |

`ordered` と `chaos` は**スイッチ1つだけの違い**です。数値では faceA=0 が「摂動の成長 0/18・厳密な周期 22」、
faceA=2 が「6/18・周期なし」。展示ではこの2本を並べるのが核になります。

## 配線が見えるところまで寄ったもの

32×18 マスを 1 マス 60px で描いた接写。カードの線分・十字・V字、白の丸(輪郭)と黒の丸(塗り)が
一枚ずつ判別でき、興奮がどの配線を伝って、どの丸を通って進むかが追える。
`neurons_selforg.html` でホイールを回して寄ったときと同じ表示。

| ファイル | 内容 |
|---|---|
| `wire_spiral` | スパイラル相の接写。波面が個々の線を伝い、後ろに不応期の尾が褪せていく。青は抑制性ニューロンの発火 |
| `wire_chaos` | 同じ配線・同じ視野で回路の帰還だけを入れたもの。波面が途中で切れる様子が一本ずつ見える |
| `wire_deck` | **印刷されたデッキそのもの**(交差 1/6、丸のみ 1/6、白黒 1:1)。実際のゲームのカード構成と、そこを活動が這う様子 |

## 比較用

| ファイル | 内容 |
|---|---|
| `chaos_short` | 同じ回路フィードバックだが R=6。波長が約3マスしかなく、遠目には砂嵐に見える |
| `chaos_lif` | もう一つのカオス経路(漏れ積分発火)。cross=0.75, q=0.9, R=4, θ=1.5, leak=0.95 |
| `damage_lif` | 同上 + 摂動注入。この回は 11.5% までしか広がっていない — カオス相でも摂動が成長する確率は 1/3〜1/2 |

## 判定の根拠

**秩序** = 厳密な状態周期が存在し、単一ノードの摂動が完全に治癒すること。
**カオス** = 周期が検出されず、摂動の約半数が生ノードの 40〜70% に成長して定着すること。

## 再生成

すべて決定論的なので、いつでも同じものが出せます。

```
cd selforg_engine && node render_all.js          # 全部
cd selforg_engine && node render_all.js chaos    # 1本だけ
```
